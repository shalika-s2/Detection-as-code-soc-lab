# Detection-as-Code SOC Lab

A home SOC lab where I simulate MITRE ATT&CK techniques, write Sigma
detection rules for them, and validate those rules automatically
with GitHub Actions.

## Goal
Build and test real detections for common attacker behaviour
(PowerShell abuse, persistence, brute force) using Wazuh, Sysmon
and Atomic Red Team.

## Status
🚧 In progress. Week 1: lab setup.

## Stack
Wazuh · Sysmon · Atomic Red Team · Sigma · GitHub Actions · Python
